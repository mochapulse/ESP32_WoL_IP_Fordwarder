## Alias (from ~/.zshrc)

```bash
idf.py() {
    (
        source "/home/javastral/.espressif/tools/activate_idf_v6.0.2.sh" > /dev/null 2>&1
        python3 "$IDF_PATH/tools/idf.py" "$@"
    )
}
```

All `idf.py` calls auto-source the v6.0.2 environment. No need to manually activate.
